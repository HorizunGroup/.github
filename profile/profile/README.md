# Horizun Group

![Horizun Group](https://horizunhub.com/brand/og-image.png)

## BIM, datos e IA para la construcción

Horizun Group desarrolla herramientas open source para equipos AEC: automatización de Revit, análisis con Power BI y flujos de trabajo asistidos por IA.

Operando desde 2018 · 500+ profesionales formados · 7 países de LATAM.

### Proyectos principales

- [Horizun Revit MCP](https://github.com/HorizunGroup/horizun-revit-mcp) — automatización y operaciones sobre modelos Revit.
- [Horizun PBI MCP](https://github.com/HorizunGroup/horizun-pbi-mcp) — integración de datos y reportes con Power BI.
- [Awesome BIM LATAM](https://github.com/HorizunGroup/awesome-bim-latam) — recursos para la comunidad BIM.

### Ecosistema

[Horizun Hub](https://horizunhub.com) · [PowerBIM Online](https://powerbim.online) · [YouTube](https://www.youtube.com/@HorizunHub)
